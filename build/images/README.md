# Dossier Images

Placez vos images dans ce dossier :

## Structure recommandée :

```
public/images/
├── profile/
│   └── profile-photo.jpg (ou .png)
├── projects/
│   ├── project-1.jpg
│   ├── project-2.jpg
│   ├── project-3.jpg
│   └── project-4.jpg
└── logos/
    └── (logos de partenaires si nécessaire)
```

## Formats recommandés :
- **Photo de profil** : JPG ou PNG, format carré (1:1), taille recommandée : 400x400px minimum
- **Images de projets** : JPG ou PNG, format paysage (16:9), taille recommandée : 1200x675px minimum

## Optimisation :
Pour de meilleures performances, compressez vos images avant de les ajouter :
- Utilisez des outils comme TinyPNG, ImageOptim ou Squoosh
- Format WebP recommandé pour une meilleure compression (si supporté)
